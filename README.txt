README - Kokisha Portfolio Website

This project is a personal portfolio website built using HTML and CSS. 
It showcases personal details, education, projects, skills, certifications, and achievements. 
The site is designed with a sidebar navigation and responsive layout.

-------------------------------------------
Features:
-------------------------------------------
1. Sidebar Navigation
   - Contains links to Home, About, Education, Projects, and Contact sections.

2. Home Section
   - Displays introduction with typing animation for "Computer Science Engineer".

3. About Section
   - Profile picture and personal details.
   - Skills and interests.
   - Certifications & Achievements.
   - Internship details.
   - Links to LinkedIn and GitHub.

4. Education Section
   - Details of academic background including B.E., HSC, and SSLC.

5. Projects Section
   - Lists major projects with GitHub link to explore them further.

6. Contact Section
   - Includes address, phone, and email for contacting.

7. Footer
   - Copyright information.

-------------------------------------------
Technologies Used:
-------------------------------------------
- HTML5
- CSS3 (with animations and responsive design)

-------------------------------------------
Instructions to Run:
-------------------------------------------
1. Save the file as 'index.html'.
2. Make sure the image paths (e.g., G:/img.jpg, G:/edu.jpeg, etc.) are correct on your system.
3. Open the file in any modern browser (Google Chrome, Firefox, Edge, etc.).
4. Use the sidebar to navigate between sections.

-------------------------------------------
Customization:
-------------------------------------------
- Replace image paths with your own images.
- Update content like name, skills, education, projects, and contact details as needed.
- Modify CSS to adjust colors, fonts, or layout as per your style preferences.
